# @muushig/client (planned)

React + Vite single-page app embedded as a Discord Activity via the Discord
Embedded App SDK. Connects to `@muushig/server` with the Colyseus JS client and
renders the synced `GameState`. Cards are drawn from a bundled SVG deck through a
`PlayingCard` component (never hand-drawn in CSS).

Not yet implemented — see the open issues / milestone.
